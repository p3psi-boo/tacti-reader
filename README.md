
TactiReader - 战术阅读器

专为战术阅读、快速跳转等工程手册阅读场景设计的pdf阅读器

▶️ 快速运行

1. 安装依赖
pip install PyMuPDF PyQt5

2. 克隆仓库
git clone https://gitee.com/Mr_newbee666/tacti-reader.git
cd tacti-reader

3. 启动程序
python tactireader.py

4. （可选）直接打开文件
打开 PDF
python tactireader.py path/to/your.pdf

打开笔记本 (.tactinote)
python tactireader.py path/to/your.tactinote

💡 要求：Python 3.7+  
✅ 支持 Windows / macOS / Linux
